Ниже план, разбитый на **независимые логически завершенные задачи**. 

# 1. Создать каркас приложения и маршрутизацию

**Промпт**

> Создай React-приложение со следующей структурой:
>
> * `src/components`
> * `src/pages`
> * `src/services`
> * `src/hooks`
> * `src/types`
> * `src/styles`
>
> Главная страница должна содержать мастер (wizard) заполнения анкеты.
>
> Пока без логики API.
>
> Добавь базовую адаптивную верстку, чтобы корректно отображалось на мобильных устройствах и десктопе.
>
> Все компоненты должны быть функциональными с использованием React Hooks.

---

# 2. Реализовать пошаговую форму

**Промпт**

> Реализуй пошаговую форму (wizard), где на экране отображается только один вопрос.
>
> Последовательность шагов:
>
> 1. Телефон
> 2. Имя ребенка
> 3. Возраст
> 4. Главный герой
> 5. Приключение
> 6. Атмосфера сказки
> 7. Интересы
>
> Должны работать кнопки:
>
> * Далее
> * Назад
>
> Следующий шаг доступен только после заполнения текущего.
>
> На последнем шаге отображается кнопка **Создать книгу**.

---

**Промпт**

> Реализуй все поля формы согласно спецификации API.
>
> Поля:
>
> Телефон
>
> Имя ребенка
>
> Возраст:
>
> * 1–3 года
> * 3–4 года
> * 5–6 лет
> * 7–8 лет
>
> Главный герой:
>
> * Сам ребенок
> * Котик
> * Медвежонок
> * Дракончик
> * Единорог
> * Супергерой
> * Свой вариант
>
> Приключение:
>
> * Найти сокровище
> * Спасти друга
> * Попасть в волшебный мир
> * Научиться смелости
> * Найти магический предмет
> * Путешествие в космос
> * Свой вариант
>
> Атмосфера:
>
> * Добрая и уютная
> * Смешная
> * Волшебная
> * Приключенческая
> * Перед сном

---

# 4. Добавить валидацию формы

**Промпт**

> Добавь полную клиентскую валидацию.
>
> Требования:
>
> * все поля обязательны;
> * телефон обязателен;
> * имя обязательно;
> * максимум 120 символов для любого текстового поля;
> * интересов можно выбрать максимум три;
> * если выбран "Свой вариант", соответствующее текстовое поле становится обязательным.
>
> Пользователь не может перейти дальше, пока текущий шаг не заполнен корректно.

---

# 5. Реализовать сервис работы с API

**Промпт**

> Создай отдельный сервис для работы с API.
>
> Реализуй методы:
>
> * generateStory()
> * generateCover()
> * generateScenes()
> * generateBook()
>
> Используй fetch или axios.
>
> Методы должны принимать необходимые параметры и возвращать Promise.
>
> Логику работы с HTTP не смешивать с UI.

---

# 6. Реализовать последовательную генерацию книги

**Промпт**

> После успешного заполнения формы необходимо последовательно выполнить API:
>
> 1. POST /generate-story
> 2. POST /generate-cover
> 3. POST /generate-scenes
> 4. POST /generate-book
>
> Следующий запрос выполняется только после успешного завершения предыдущего.
>
> Все необходимые данные передавать согласно Swagger.
>
> При ошибке выполнение цепочки должно останавливаться.

---

# 7. Реализовать отображение прогресса генерации

**Промпт**

> После отправки формы вместо формы показать экран прогресса.
>
> Во время выполнения API отображать текущий этап:
>
> Шаг 1/4 — Создаем сценарий
>
> Шаг 2/4 — Рисуем обложку
>
> Шаг 3/4 — Генерируем иллюстрации
>
> Шаг 4/4 — Собираем книгу
>
> Текущий шаг должен выделяться визуально.
>
> Пользователь должен понимать, какой этап выполняется сейчас.

---

# 8. Показать обложку после второго этапа

**Промпт**

> После успешного выполнения `/generate-cover` сервер возвращает ссылку на изображение обложки.
>
> Сразу после получения ссылки необходимо:
>
> * показать изображение под блоком прогресса;
> * изображение должно автоматически обновиться;
> * до окончания генерации изображение не является ссылкой.

---

# 9. Показать готовую книгу после завершения генерации

**Промпт**

> После успешного выполнения `/generate-book` сервер возвращает ссылку на PDF.
>
> После получения PDF необходимо:
>
> * сделать изображение обложки ссылкой;
> * под изображением вывести текст:
>
> **Скачать книгу**
>
> Картинка и текст должны быть обернуты одной ссылкой, ведущей на PDF.
>
> Пользователь должен иметь возможность скачать книгу, нажав как на картинку, так и на текст.

---

# 10. Реализовать обработку ошибок

**Промпт**

> Если любой API-запрос завершается ошибкой:
>
> * остановить процесс генерации;
> * показать желтый значок предупреждения;
> * вывести сообщение:
>
> **Произошла ошибка. Попробуйте повторить шаг.**
>
> Ниже показать кнопку:
>
> **Повторить**
>
> При нажатии необходимо повторить только тот этап, на котором произошла ошибка, а не запускать процесс генерации заново.
>
> Если повторный запрос выполнится успешно, генерация продолжается со следующего этапа.

---

# 11. Финальная полировка интерфейса

**Промпт**

> Выполни финальную полировку интерфейса.
>
> Требования:
>
> * единый современный стиль;
> * аккуратные отступы;
> * адаптивность;
> * плавные переходы между шагами;
> * состояние загрузки кнопок;
> * отключение элементов управления во время выполнения запросов;
> * корректное отображение на мобильных устройствах;
> * чистый и читаемый код без дублирования логики.
